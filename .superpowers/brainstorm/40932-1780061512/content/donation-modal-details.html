Custom Amount Input

When the user clicks "Custom amount", how should it work?

A

Inline input in modal

Clicking "Custom amount" expands an input field right in the modal. User types a number, then clicks "Continue" to open BMAC.

B

Open BMAC directly

Clicking "Custom amount" opens the BMAC page in a new tab — user chooses the amount on BMAC's own interface.
