Donation Section — Layout Options

Where and how should the donation module appear in the result view?

A

Modal Approach

A "Buy me a coffee" button sits below the two existing buttons. Clicking it opens a modal showing preset amounts ($5 / $10 / $25 / Custom), then redirects to Buy Me a Coffee in a new tab.

B

Inline Buttons

Amount buttons shown directly in the footer — no modal. Each button links straight to Buy Me a Coffee. Cleaner and fewer clicks, but adds more visual weight to the footer.
